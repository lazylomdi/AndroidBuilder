# romforge's CLI subcommands (list-versions, find-device, detect-device,
# build with explicit flags) use only the Python standard library.
#
# The interactive TUI mode (`python3 romforge.py tui`, or running with no
# arguments at all) needs questionary for arrow-key menus:
questionary>=2.0
# If questionary isn't installed, the TUI mode prints a message and exits
# rather than crashing -- the CLI subcommands still work without it.

# External, non-Python tools you need on PATH depending on what you use:
#   - repo        https://source.android.com/setup/develop#installing-repo
#   - git
#   - adb         (only for `detect-device` / auto-detection during `build`)
#   - docker      (only for --backend docker)
#   - gh CLI      (optional, only for triggering --backend github-actions workflows)
